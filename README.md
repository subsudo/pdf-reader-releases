# PDF Reader – Downloads

Hier liegen die fertigen Versionen von **PDF Reader**, einem schlanken PDF-Reader für Windows.

**[Neueste Version herunterladen](https://github.com/subsudo/pdf-reader-releases/releases/latest)**: die Datei `PDF-Reader.exe` unter «Assets».

- Keine Installation nötig: exe an einen festen Ort legen (z. B. `%LOCALAPPDATA%\Programs\PDF Reader`) und starten.
- Läuft auf Windows 10 und 11 (64 Bit), .NET muss nicht installiert sein.
- Die App sucht beim Start selbst nach Updates und aktualisiert sich auf Wunsch.
